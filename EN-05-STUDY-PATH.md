# 05 — Study path

## Foundations
1. **Linux:** terminal, permissions (`chmod`, `chown`, why `777` is dangerous), processes, packages.
2. **Networking:** IP, ports, TCP/UDP, DNS, HTTP/HTTPS, TLS, NAT, proxy/CDN.
3. **Web:** cookies, sessions, CORS, security headers.

## Offensive security (to defend better)
4. **An intro hacking & pentest course** — Kali, recon, Nmap, Netcat, exploits.
5. **OWASP Top 10.**
6. **PortSwigger Web Security Academy** (free hands-on labs).
7. **TryHackMe / Hack The Box** — legal practice machines.

## Defensive security
8. Cloudflare (DNS, WAF, rules, Zero Trust/Access).
9. Modern auth: WebAuthn/passkeys, TOTP, password hashing (Argon2).
10. Email: SPF, DKIM, DMARC, BIMI.

## Building with AI
11. Clear, verifiable requests to agents.
12. Automated tests and code review.
13. Git/GitHub: branches, PRs, review, rollback.

## Law
14. Your country's computer-crime and data-protection laws (Brazil: art. 154-A, Marco Civil, LGPD).

## Weekly practice
- 1 course lesson + 1 lab.
- 1 passive check of your own domain ([EN-02](EN-02-PASSIVE-RECON.md)).
- Write down what you learned.
